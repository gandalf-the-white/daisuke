#+title: Connection

* Introduction
This chapter describes the various interactions within the platform. All instances are hosted in separate /jails/, including in different virtual machines.

* PostgreSQL
** Inside the jail
#+begin_src shell
$ bastille cmd postgres-server sockstat -4 -l
USER     COMMAND      PID FD PROTO LOCAL ADDRESS         FOREIGN ADDRESS
postgres postgres   11061  6 tcp4  10.17.89.220:5432     *:*
#+end_src

** Outside the jail
#+begin_src shell
nc -vz 192.188.200.102 5432
192.188.200.102 5432 (postgresql) open
#+end_src

** From outside
We suppose a right permission from the client in /pg_hba.conf/
#+begin_src shell
PGPASSWORD='CHANGE_ME' \
psql -h 192.188.200.102 -p 5432 -U ldes -d ldes
psql (18.4, server 17.10)
Type "help" for help.

ldes=>
#+end_src
